# Third-party software

This project does not bundle third-party executables or libraries. It invokes the following software when installed separately by the user:

- [yt-dlp](https://github.com/yt-dlp/yt-dlp) — see its [license file](https://github.com/yt-dlp/yt-dlp/blob/master/LICENSE).
- [FFmpeg](https://ffmpeg.org/) — see its [legal notices](https://ffmpeg.org/legal.html). The applicable license depends on how the user's FFmpeg build was configured.
- [Tampermonkey](https://www.tampermonkey.net/) — browser userscript manager; distributed separately by its publisher.
- [Firefox](https://www.mozilla.org/firefox/) — web browser.
- [Mixxx](https://mixxx.org/) — DJ software.
